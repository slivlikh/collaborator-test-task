```bash
pnpm build
```

1. Налаштування енваеремента для тестів, vitest/jest, при обранні vitest (бажано) зробити міграцію з webpack на vite. Покриття тестами components/Card 
   1. Якщо залишатися на webpack, то розділити конфіки на common, dev та prod з подальшою оптимізацією prod конфіга  
2. Міграція на TypeScript, оскільки PropTypes depricated (я свідомо не додавав їх у проект)
3. Запровадити систему ізоляції стилів CSS-in-JS або CSS Modules
4. Оновлення npm пакетів
5. Винести в Storybook компоненти з ui-кіта
6. Абсолютні одиниці виміру змінити на відності усюди де це має сенс.
7. В компоненті ui/components/Dropdown при відкритті зробити скрол до обраного айтема
8. В ui/components/Card/Description додати тултип який з'являтиметься при наведенні, якщо текст кліпнутий
